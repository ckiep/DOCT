# VERNY Bakery — сайт-лендинг

Одностраничный сайт пекарни VERNY BAKERY (этап 1 по ТЗ): первый экран, «О нас», меню,
галерея, предзаказ с самовывозом, контакты, подвал. Языки: KZ / RU / EN.
Обычный статический сайт: HTML + CSS + JS, без сборки и без сервера.

## Структура

```
verny-bakery/
├── index.html            разметка и все тексты на русском
├── assets/css/style.css  стили (цвета бренда — переменные в начале файла)
├── assets/js/i18n.js     переводы на казахский и английский
├── assets/js/main.js     меню, галерея, форма предзаказа → WhatsApp, переключение языка
├── assets/img/           favicon, иконка для iPhone, картинка для превью ссылки
└── photos/               фотографии
```

## Контакты: где их менять

WhatsApp и телефон уже настоящие. Instagram пока **заглушка**, адрес нужно подтвердить.
Чтобы поменять значение, замените его во всех местах из таблицы:

| Что | Значение | Где встречается |
|---|---|---|
| WhatsApp (только цифры, с кодом страны) | `77005289504` | `index.html` (3 ссылки), `assets/js/main.js` → `WA_NUMBER` |
| Телефон для звонка | `tel:+77005289504` и `+7 700 528 95 04` | `index.html` (контакты, JSON-LD), `assets/js/main.js` → `PHONE_LABEL` |
| Instagram (заглушка) | `https://instagram.com/` | `index.html` (шапка, галерея, контакты, JSON-LD) |
| Адрес | `ул. Т. Утепова 31, Казахфильм (17)` | `index.html` (контакты, карта, JSON-LD), перевод в `assets/js/i18n.js` |

Режим работы (07:30–22:00, без выходных, как на двери пекарни) задан в `index.html` и в `assets/js/main.js` (`OPEN`, `CLOSE`):
по нему форма проверяет время самовывоза.

## Как добавить или изменить текст

1. Поменяйте русский текст в `index.html`.
2. В `assets/js/i18n.js` добавьте (или переименуйте) строку:
   `"Русский текст": ["Қазақша мәтін", "English text"]`.

Ключ должен в точности совпадать с текстом в `index.html`, иначе перевод не подставится.

## Как посмотреть локально

```bash
cd verny-bakery && python3 -m http.server 8000
```

Откройте http://localhost:8000.

## Как залить на хостинг (hoster.kz или любой другой с cPanel)

1. Возьмите архив `verny-bakery-site.zip`: внутри только файлы сайта, без этого README.
2. Панель хостинга → «Файловый менеджер» → папка сайта: `public_html`
   (у некоторых тарифов — `www` или `public_html/<домен>`).
3. Удалите из папки заглушку хостинга (`index.html` / `default.html`), если она там есть.
4. «Загрузить» → выберите архив → после загрузки нажмите на нём «Извлечь» (Extract).
   В корне `public_html` должны оказаться `index.html`, `.htaccess`, `robots.txt` и папки `assets`, `photos`.
5. Если домен куплен в том же hoster.kz, привяжите его к хостингу в панели.
   Если домен куплен у другого регистратора, пропишите у него NS-серверы hoster.kz
   (они указаны в письме о создании хостинга).
6. В панели включите бесплатный SSL (Let's Encrypt / AutoSSL). Когда сертификат выпущен,
   уберите решётки у трёх строк `Rewrite…` в `.htaccess`, чтобы сайт всегда открывался по https.

Сайт в зоне `.kz` должен размещаться на сервере в Казахстане, поэтому хостинг в KZ — правильный выбор.

## Дальнейшее развитие (по ТЗ)

Онлайн-меню, корзина, оплата, доставка, личный кабинет, лояльность, филиалы.
Под это всё уже разложено по отдельным файлам: кнопка «Смотреть всё меню» сейчас
открывает окно с меню (`#fullmenu` в `index.html`), а позже её можно перевести на
страницу онлайн-меню. Форма предзаказа собирает данные в одном месте (`main.js`),
поэтому отправку в WhatsApp легко поменять на отправку в CRM или на свой сервер.
