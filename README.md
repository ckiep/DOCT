# ticket_alert — оповещения о дешёвых авиабилетах

Программа следит за ценами на нужные вам направления и присылает в Telegram
сообщение, когда находит билет не дороже заданной суммы:

```
✈️ Москва → Стамбул, декабрь
Билеты не дороже 12 000 ₽:

• 05.12 10:15 — 9 870 ₽ (было 11 200 ₽), прямой, PC 395 — купить
• 09.12 06:40 — 10 450 ₽, 1 пересадка, TK 414 — купить
```

- Можно следить за любым количеством маршрутов: в одну сторону или туда-обратно,
  на конкретный день или на весь месяц, только прямые рейсы или любые.
- Сообщение приходит только о **новых** вариантах и о тех, что **подешевели**,
  поэтому одно и то же повторно не присылается.
- Цены берутся из [Aviasales Data API](https://support.travelpayouts.com/hc/en-us/articles/203956163-Aviasales-Data-API)
  (Travelpayouts). Это кэш поисков пользователей Aviasales за последние дни, а не
  живая выдача, поэтому перед покупкой цену нужно проверить по ссылке.
- Нужен только Python 3.11+, сторонние библиотеки не нужны.

## Настройка

1. **Токен цен.** Зарегистрируйтесь на [travelpayouts.com](https://www.travelpayouts.com/)
   (бесплатно) и скопируйте API-токен в разделе профиля.
2. **Бот Telegram.** Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`
   и получите токен бота.
3. **Ваш chat_id.** Отправьте своему боту любое сообщение, затем откройте в браузере
   `https://api.telegram.org/bot<ТОКЕН_БОТА>/getUpdates` и найдите `"chat":{"id": ...}`.
   Это число и есть `chat_id`. Для группы добавьте бота в группу (id будет отрицательным).
4. **Настройки.** Скопируйте пример и впишите токены и маршруты:

   ```bash
   cp config.example.toml config.toml
   ```

   Токены можно не хранить в файле, а задать переменными окружения
   `TRAVELPAYOUTS_TOKEN`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.

Пример маршрута:

```toml
[[routes]]
name = "Москва → Стамбул, декабрь"
origin = "MOW"          # IATA-код города или аэропорта
destination = "IST"
departure = "2026-12"   # месяц (YYYY-MM) или день (YYYY-MM-DD)
# return = "2026-12"    # раскомментируйте для билетов туда-обратно
max_price = 12000       # присылать билеты не дороже этой суммы
direct_only = false     # true — только прямые рейсы
```

Коды городов: Москва `MOW`, Санкт-Петербург `LED`, Сочи `AER`, Казань `KZN`,
Стамбул `IST`, Анталья `AYT`, Дубай `DXB`, Ереван `EVN`, Тбилиси `TBS`, Бангкок `BKK`.
Остальные можно найти по запросу «IATA код <город>».

## Запуск

Сначала проверьте настройки без Telegram — найденное просто напечатается в консоль,
и ничего не запомнится:

```bash
python3 -m ticket_alert --once --dry-run
```

Постоянная работа (проверка каждые `interval_minutes` минут):

```bash
python3 -m ticket_alert
```

Или разовая проверка по расписанию через cron (например, каждые 30 минут):

```cron
*/30 * * * * cd /path/to/DOCT && python3 -m ticket_alert --once >> ticket_alert.log 2>&1
```

Параметры: `-c путь/к/config.toml` — другой файл настроек, `-v` — подробный лог.
С `--once` программа возвращает код 1, если хотя бы один маршрут проверить не удалось.

История оповещений хранится в `ticket_alert.db` (SQLite) рядом с `config.toml`.
Удалите этот файл, если хотите заново получить все текущие варианты.

## Разработка

```bash
python3 -m unittest discover -s tests -t .
```

Структура:

- `ticket_alert/travelpayouts.py` — запрос цен к API;
- `ticket_alert/checker.py` — отбор дешёвых вариантов и текст сообщения;
- `ticket_alert/storage.py` — история отправленного (чтобы не повторяться);
- `ticket_alert/notifiers.py` — отправка в Telegram или в консоль;
- `ticket_alert/config.py` — чтение и проверка `config.toml`.
