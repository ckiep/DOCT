# ticket_alert — Telegram-бот дешёвых авиабилетов

Бот следит за ценами на авиабилеты и пишет в Telegram, когда появляется билет
не дороже вашего бюджета. Всё настраивается кнопками прямо в чате:

- **➕ Добавить направление**: откуда → куда → месяц (или конкретный день) →
  в одну сторону или туда-обратно (выходные 2–4 дня, неделя 5–9, две недели 10–16
  или любой срок) → бюджет.
  Вместо города прилёта можно выбрать **🌍 Куда угодно за границу**, и бот будет присылать
  любые зарубежные города, куда билет укладывается в бюджет (рейсы внутри своей страны
  сюда не попадают). Направлений может быть сколько угодно (до 20).
- **🧠 Только выгодные цены** — вместо бюджета: бот сам считает обычную цену
  на направление (медиана самых дешёвых билетов по датам) и пишет, когда билет хотя бы
  на 15% дешевле. Работает для конкретного города, не для «куда угодно».
- **📋 Мои направления**: список с кнопками удаления.
- **🔥 Куда дёшево**: 20 самых дешёвых зарубежных направлений из вашего города на выбранный месяц.
  Из подборки можно сразу подписаться на такие билеты.
- **🔄 Проверить сейчас**: проверка, не дожидаясь плановой (по умолчанию раз в час).

```
🌍 Алматы → за границу, декабрь 2026
Билеты не дороже 40 000 ₸:

• Бишкек — 21 300 ₸, 07.12 07:20, прямой, KC 109 — купить
• Ташкент — 33 900 ₸ (было 38 400 ₸), 12.12 09:10, прямой, HY 762 — купить
```

Бот присылает только **новые** варианты и те, что **подешевели**, поэтому одно и то же
повторно не придёт. В оповещениях видно, насколько цена ниже обычной («−23% к обычной
цене»), а значок 🔥 означает самую низкую цену с тех пор, как бот следит за направлением. Когда даты направления проходят, бот удаляет его и сообщает об этом.

Цены берутся из [Aviasales Data API](https://support.travelpayouts.com/hc/en-us/articles/203956163-Aviasales-Data-API)
(Travelpayouts). Это кэш поисков пользователей Aviasales за последние дни, а не живая
выдача, поэтому перед покупкой цену нужно проверить по ссылке.

Нужен только Python 3.11+, сторонние библиотеки не нужны.

## Настройка

1. **Токен цен.** Зарегистрируйтесь на [travelpayouts.com](https://www.travelpayouts.com/),
   подключитесь к программе Aviasales и скопируйте токен в разделе «Профиль» → «API токен».
2. **Бот Telegram.** Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`
   и получите токен бота. Он выглядит как `1234567890:AAH...`.
3. **Ваш ID в Telegram.** Напишите [@userinfobot](https://t.me/userinfobot): он ответит числом.
   Это владелец бота: он решает, кто ещё может им пользоваться.
4. **Файл настроек.** Скопируйте пример (`copy` на Windows, `cp` на Mac/Linux) и впишите
   токены и ID:

   ```
   copy config.example.toml config.toml
   notepad config.toml
   ```

   ```toml
   [travelpayouts]
   token = "токен Travelpayouts"

   [telegram]
   bot_token = "1234567890:AAH..."
   chat_id = "123456789"
   ```

   Токены можно не хранить в файле, а задать переменными окружения
   `TRAVELPAYOUTS_TOKEN`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.

По умолчанию цены в тенге (`currency = "kzt"`), ссылки ведут на aviasales.kz
(`market = "kz"`). Можно поменять в разделе `[travelpayouts]`.

### Доступ для других людей

Другу или брату достаточно найти бота в Telegram и нажать `/start`. Вам придёт сообщение
«👤 … хочет пользоваться ботом» с кнопками **✅ Разрешить** / **✖ Отклонить**. После
разрешения у человека будут свои направления и свои оповещения. Команда `/users`
показывает, у кого есть доступ, и позволяет его закрыть (направления человека удаляются).

Чтобы пускать всех без спроса, поставьте `public = true` в разделе `[telegram]`.
Пока бот запущен на вашем компьютере, он работает только когда компьютер включён.

### Партнёрский маркер (необязательно)

Условия программы Aviasales в Travelpayouts разрешают личные бронирования
(Personal bookings). Если указать свой партнёрский ID в `marker`, ссылки «купить»
в оповещениях станут партнёрскими, и с подтверждённых покупок по ним, в том числе
ваших собственных, начисляется 1,1–1,3% стоимости билета. Выплата обычно через
30 дней после подтверждения заказа.

```toml
[travelpayouts]
marker = "123456"       # или "123456.bot", чтобы отличать в статистике покупки из бота
```

Чтобы узнать свой ID, создайте в кабинете любую партнёрскую ссылку на Aviasales
и перейдите по ней: в адресе открывшейся страницы будет `marker=...`, ваш ID — это
цифры до точки.

### Автопостинг в канал

Бот может сам публиковать лучшие находки в ваш Telegram-канал. Раз в несколько часов он ищет
самые дешёвые билеты за границу из указанных городов на ближайшие месяцы (в одну сторону
и туда-обратно на 3–14 дней) и для каждого города считает обычную цену по всем датам месяца.
В канал попадает только то, что дешевле обычного хотя бы на `min_discount` процентов (20%).

```
🔥 Алматы → Стамбул — 40 000 ₸
📅 В одну сторону: 04.12 в 05:45
✈️ Прямой рейс, PC 101
📉 −38% к обычной цене (около 65 000 ₸)
            [ ✈️ Купить билет ]
   [ 🔔 Следить за своими направлениями ]
```

- Не больше `max_posts_per_day` постов в сутки и `max_posts_per_run` за раз, ночью тишина
  (`post_hours`).
- Одно и то же направление не повторяется неделю, если только цена не упала ещё на 5%.
- 🏆 в посте — самая низкая цена, которую бот видел на этом направлении.
- Кнопка «Следить за своими направлениями» ведёт в бота, так канал приводит пользователей.
- К партнёрскому маркеру в ссылках канала добавляется `.channel`, поэтому в статистике
  Travelpayouts видно, сколько покупок пришло из канала.

Как включить: добавьте бота в администраторы канала с правом публиковать сообщения
и впишите адрес канала в раздел `[channel]`:

```toml
[channel]
id = "@traveleasy_kz"
origins = ["ALA", "NQZ"]
```

Команда `/post` (только для владельца) публикует находки сразу, не дожидаясь расписания.

## Запуск

```
py -m ticket_alert
```

(на Mac/Linux `python3 -m ticket_alert`). Откройте своего бота в Telegram и нажмите
`/start`, внизу появится меню. Бот работает, пока открыто окно и включён компьютер.

Другие режимы:

- `py -m ticket_alert --once` — один раз проверить все направления, разослать оповещения
  и выйти. Подходит для запуска по расписанию (cron, Планировщик заданий Windows), но
  кнопки в Telegram в этом режиме не работают.
- `py -m ticket_alert --dry-run` — один раз проверить направления и напечатать найденное
  в консоль, ничего не отправляя и не запоминая.
- `-c путь/к/config.toml` — другой файл настроек, `-v` — подробный лог.

Направления и история оповещений хранятся в `ticket_alert.db` (SQLite) рядом
с `config.toml`, а справочник городов — в `cities.json` и `countries.json` там же
(скачивается один раз и обновляется раз в месяц). Удалите `ticket_alert.db`, чтобы
начать с чистого листа.

## Запуск на сервере (круглосуточно)

Подойдёт самый простой VPS: 1 ядро, 1 ГБ памяти, **Ubuntu 24.04** или Debian 12 (нужен
Python 3.11+, в них он уже есть), без панели управления.

1. Остановите бота на компьютере (Ctrl+C). Две запущенные копии мешают друг другу.
2. Скопируйте папку с ботом на сервер. В Windows это можно сделать из командной строки,
   открытой на Рабочем столе (вместо `IP` — адрес сервера):

   ```
   scp -r DOCT-claude-inspiring-darwin-gzyzrh root@IP:/root/ticket_alert
   ```

   Вместе с кодом скопируются `config.toml` и `ticket_alert.db` (ваши направления и доступы).
3. Подключитесь к серверу и установите бота как службу:

   ```
   ssh root@IP
   cd /root/ticket_alert
   bash deploy/install.sh
   ```

Бот будет сам запускаться после перезагрузки сервера и перезапускаться при сбоях. Время
для публикаций в канал считается по Казахстану (`Asia/Almaty`).

- Лог: `journalctl -u ticket-alert -f` (выход — Ctrl+C).
- Обновить бота: скопируйте новую версию тем же `scp` и снова выполните
  `bash deploy/install.sh`. Код и `config.toml` обновятся, база на сервере останется.
- Перезапустить или остановить: `systemctl restart ticket-alert`, `systemctl stop ticket-alert`.

## Разработка

```bash
python3 -m unittest discover -s tests -t .
```

Структура:

- `ticket_alert/bot.py` — диалоги и кнопки Telegram-бота, главный цикл;
- `ticket_alert/checker.py` — проверка цен: что нового и что подешевело;
- `ticket_alert/travelpayouts.py` — запрос цен к API Aviasales;
- `ticket_alert/places.py` — справочник городов (название ↔ IATA-код);
- `ticket_alert/formatting.py` — тексты сообщений;
- `ticket_alert/storage.py` — направления и история оповещений (SQLite);
- `ticket_alert/telegram.py` — Telegram Bot API;
- `ticket_alert/dates.py` — разбор и описание дат;
- `ticket_alert/config.py` — чтение и проверка `config.toml`.
